# عم عبده + Groq — بروتوتايب محلي فقط

هذه تجربة تطوير معتمدة على الجهاز فقط. النشر على GitHub Pages يبقى كما هو: المساعد محلي وحتمي، والمفتاح لا يوجد في المتصفح ولا في المستودع.

## ما الذي يتغير محليًا

- `js/assistant.js` يحسب الإجابة كما يفعل دائمًا: الأرقام، الفترات، نطاق المالك، وأي قرار حفظ يمر بمعاينة وتأكيد صريح.
- `js/assistant-groq.js` يُفعّل فقط إذا كانت الصفحة على `localhost` أو `127.0.0.1` **و** كان `/api/groq/health` يُجيب `enabled: true`. في تلك الحالة فقط يطلب من Groq إعادة صياغة الإجابة المحلية.
- البيانات المرسلة إلى Groq هي نص الإجابة المحلية بعد إزالة وسوم HTML + دور المستخدم + نص السؤال. لا يُرسل `state` الخام ولا كلمات المرور ولا مفاتيح Supabase.
- أنواع الردود المعلوماتية فقط هي القابلة لإعادة الصياغة (`cashbox`، `summary`، `income`، `arrears`، `compound`، `my_bill`…). أوامر الحفظ والتأكيد والإلغاء والرفض ومعالجة الأخطاء لا تمر على النموذج.
- إذا فشل الاتصال أو غاب المفتاح أو رفض النموذج الإجابة، يظهر الرد المحلي الأصلي دون أي رسالة خطأ للمستخدم.
- يتميز الرد المُعاد صياغته بسطر «صياغة Groq تجريبية · الأرقام من بيانات التطبيق»، ويظل عنوان رأس المحادثة «متاح الآن · صياغة Groq تجريبية».

## التشغيل

1. أضف المفتاح إلى `Manzil/.env` (الملف مستبعد في `.gitignore`):

   ```dotenv
   GROQ_API_KEY=gsk_...
   GROQ_MODEL=openai/gpt-oss-20b
   ```

2. من جذر المستودع:

   ```sh
   npm install
   npm run dev:groq
   ```

3. افتح <http://127.0.0.1:8787/> وسجّل الدخول كمدير أو مالك، ثم اسأل سؤالًا معلوماتيًا مثل «رصيد الخزنة كام؟».

السيرفر يخدم الملفات الثابتة ويوفر مسارات same-origin:

- `GET /api/groq/health` — حالة المفتاح والنموذج فقط، بدون أي سر.
- `POST /api/groq/chat` — يضيف `Authorization: Bearer …` من `.env` ويتصل بـ `https://api.groq.com/openai/v1/chat/completions`.

الـ CSP لم يتغير؛ المتصفح لا يعرف عنوان Groq إطلاقًا.

## ضوابط

- السيرفر يرفض الطلبات الأكبر من 16 KB، ويقص الرسائل إلى 8 رسائل / 6000 حرف، ويثبّت النموذج من `.env` بغض النظر عما يرسله المتصفح، ويحدد `max_tokens` بـ 700، ومهلة 20 ثانية.
- أخطاء Groq تُعرض كرمز حالة فقط؛ لا يُعاد تمرير نص الاستجابة الذي قد يعكس محتوى الطلب.
- `npm run check:secrets` يكشف مفاتيح `gsk_` في الملفات المتتبعة.
- لا توجد Edge Function ولا تغيير في Supabase أو RLS لهذه التجربة.

## الفحوص

```sh
npm test -- tests/assistant-groq.test.cjs
npm run typecheck
npm run check:index
npm run check:secrets
```

إذا أردت الربط في الإنتاج لاحقًا، المسار الصحيح هو Edge Function بسر مخزّن في Supabase Dashboard، مع قرار وتوثيق مستقلين لتعديل قاعدة «المساعد محلي».
